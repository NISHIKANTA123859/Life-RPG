# Life RPG ⚔️

A gamified life dashboard that transforms daily tasks, habits, and self-improvement into an immersive RPG experience. Level up your character, complete daily quests, build skill trees, earn rewards, and track your real-life progress.

**Repository**: [https://github.com/NISHIKANTA123859/Life-RPG](https://github.com/NISHIKANTA123859/Life-RPG)

---

## Project Structure

```
Life RPG/
├── FRONTNED/       # React + Vite + TypeScript frontend application
├── BACKEND/        # Backend API services
├── DATABASE/       # Database schemas and migrations
├── ML/             # Machine learning and intelligence pipelines
└── ASSETS/         # Media, icons, and static game assets
```

---

## Frontend Setup & Running Locally

Navigate to the `FRONTNED` directory:

```bash
cd FRONTNED
npm install
npm run dev
```

The application will run at:
`http://localhost:5173/`

### Features
- **Dashboard**: Character stats, daily quest overview, XP progression, and level-up milestones.
- **Quest Board**: Dynamic quests categorized by Intellect, Endurance, Mind, and Discipline.
- **Character Profile**: Detailed attribute distribution, radar charts, and equipped gear.
- **Skill Tree**: Branching progression for multiple skill paths.
- **Shop & Inventory**: Unlockable boosts, cosmetics, gear, and items.
- **AI Intelligence**: Smart recommendations and quest insights.
- **Leaderboard & Achievements**: Competitive standings and badges.
